# 难度标注与校准

本库81道题均按当前题面及实际提示逐题进行结构复核，等级由 `difficulty_profile` 三轴分值确定：

**L = 1 + 方法发现 D + 论证深度 R + 技术控制 T。**

这是便于审题一致性的工作规则，不是已验证的心理计量量表，等级尚未用模型或学生真实作答率校准。它不把高阶名词直接视为困难，也不按答案字数分级。

| 维度 | 分值 | 判据 |
|---|---:|---|
| 方法发现 D | 0 | 题面已给主要路线或只须定义代入 |
| 方法发现 D | 1 | 选择一个标准概率或分析工具 |
| 方法发现 D | 2 | 发现未直接提示的关键表示、辅助量、截断或对称化构造 |
| 方法发现 D | 3 | 自行设计满足全阶矩或整类测试函数约束的非常规新分布 |
| 论证深度 R | 0 | 一个核心论证即可；重复同类代入不增加深度 |
| 论证深度 R | 1 | 几个相连步骤或两个实质目标 |
| 论证深度 R | 2 | 多个实质引理或多段独立目标需要衔接 |
| 技术控制 T | 0 | 有限计算和直接条件代入足够 |
| 技术控制 T | 1 | 一类实质极限、积分交换、零集、边界或尾部条件需验证 |
| 技术控制 T | 2 | 多重无限操作、生成类延拓、路径条件核或扩展值合法性需联合控制 |

前置理论单列在 `prerequisites`；评定时假定解题者掌握所列工具，但不能直接引用题目要求证明的结论。题面若已经给出关键特征函数、变换或递归构造，必须把这一提示计入难度，不能按无提示版本评级。

逐题分值与理由在 `data/items.jsonl`；[逐题校核记录](review.md)列出全部81题的答案关键判断。相邻题也服从同一规则：已给Cauchy特征函数的均值计算低于自行寻找概率核；直接条件Jensen低于构造截断事件证明二阶矩必要性；11.34除发现新密度外，还要验证空间实现、两个半轴的非负归一化及整类测试函数的积分交换，因此技术控制高于B.5的单类高斯积分。

这些判断依赖背景与熟悉度。知道正弦扰动或零偏公式的人可能觉得相应题容易。高等级样本少，L8仅1题，不能单独支持稳定能力排名；等级也不能与CMC-Bench或其他题库直接比较。

后续校准建议：

1. 固定封闭题面、预算和评测条件，用多种能力不同的模型与受训人工解题者作答；区分模型族与重复采样。
2. 双重盲评或人工裁决，保留未决题，先修正题面和参考问题，再分析难度。
3. 展示每题作答数、全对率、部分分、耗时/输出预算、模型族；检查相邻等级全对率是否总体下降，同时按理论背景分层。
4. 等级倒置先检查熟悉度、知识缺口、污染、评分偏差及题族关联，不能只用一次模型结果重新贴标签。
5. 在样本足够时再考虑IRT等模型；当前81题且挑战级仅1题，不提供虚构的IRT参数或“已校准”声明。
